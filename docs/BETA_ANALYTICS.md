# Измерения семидневной беты

Миграция `202609090010` добавляет обычные SQL views без изменения игровых данных.
Все даты явно вычисляются в Europe/Moscow и не зависят от timezone подключения.

## Возвращаемость игроков

`analytics_beta_user_cohorts`: когорта — день первого сохранённого `cat_created`
пользователя. Пересоздание кота не начинает новую когорту. D1/D3/D7/D14 — активность
в конкретный календарный день после создания, а не «когда-нибудь после D7».
В знаменатель входят только пользователи с полностью закончившимся целевым днём.
Для незрелой когорты процент NULL, не 0.

Активность: тренировка, запрошенный ответ кота, человеческий reply коту,
участие в состоявшемся бою (оба участника), выбор роли события.
Просмотр профиля, вступление, генерация автономной реплики, выдача награды и
автоматическая сводка не считаются возвращением человека.

## Дворы и повторные действия

`analytics_beta_yard_daily`: уникальные активные коты/люди за день;
бой считается один раз на Двор, но оба кота активны.
`analytics_beta_yard_activation`: активация — первый день с минимум тремя
активными котами. `three_active_cats_d7` — те же минимум три (не обязательно те же
личности) в день D7 после активации; NULL до завершения D7. Неактивированные
Дворы остаются в выборке, чтобы не скрывать провалы активации.

`analytics_beta_repeat_actions`: первая и вторая тренировка, бой, участие в
событии каждого пользователя. Изменение роли в одном событии не считается
повторным событием. Участие учитывается и до финала; отменённые события исключены.
Бой фиксирует участие, но сам по себе не доказывает повторный ручной `/fight`.

## Готовый отчёт

```bash
COMPOSE_FILE=docker-compose.dev.yml bash scripts/beta_report.sh
```

Отчёт выводит агрегаты, без Telegram ID, имён, сообщений и платёжных реквизитов.
На старте зафиксировать набор тестовых групп и дату приглашения; через неделю
сопоставить отчёт с наблюдениями администраторов: обсуждают ли люди котов без
напоминаний автора. Не добавлять новые механики в течение недели, кроме исправлений
блокирующих ошибок.

## Ограничения

Training и разговоры берутся из best-effort `game_events`: потерянную публикацию
views не восстановят. Бои и роли берутся из игровых таблиц. После удаления кота
его исторические бои/роли могут потерять связь с пользователем; после удаления
пользователя история также может исчезнуть. Человеческий reply учитывается для
автора ответа, а не владельца кота, которому ответили. Активные коты считаются по
сохранившимся котам авторов действий. Обычные сообщения и реакции всей группы
бот не измеряет. До transactional outbox эти цифры — наблюдаемый нижний предел,
а не финансово точный журнал активности. Для малой закрытой беты этого достаточно.
