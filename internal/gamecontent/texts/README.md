# Процедурные тексты CatForge

Здесь лежат все игровые реплики, которые не пишет LLM. Файлы разделены по
механикам, а ключ указывает место использования.

Чтобы добавить разнообразие, добавьте новую строку в массив нужного ключа.
Вариант выбирается детерминированно по сохранённому `flavor` или `seed`, поэтому
повторный показ одного результата не меняет историю.

В строках разрешены шаблоны Go `text/template`, например:

```json
"fight.start": [
  "⚔️ {{.AttackerName}} полез на {{.DefenderName}}."
]
```

Имена полей зависят от места вызова; используемые поля показаны в уже
существующих вариантах. `go test ./internal/gamecontent` проверяет JSON,
дубликаты ключей, пустые массивы и синтаксис шаблонов. После редактирования
контента бот нужно пересобрать: JSON встраивается в бинарник.
